# Архитектура компонентов

Правила применяются ко всем React-компонентам, включая вложенные,
общие и UI-kit.

## Структура компонента

Каждый компонент размещай в отдельной папке с именем компонента в PascalCase.
View и CSS Module обязательны и называются по имени компонента:
`Button.tsx` и `Button.module.css`. Имя экспортируемого компонента
совпадает с именем папки. Хук `usePresenter` в `usePresenter.ts`
добавляй при наличии собственной логики компонента.

Типы и интерфейсы компонента размещай в `types.ts` в той же папке.

## View и presenter

- View возвращает JSX на основе props и результата собственного
  `usePresenter`, если он есть.
- Компонент и его вспомогательные файлы используют только его собственный
  `usePresenter`.
- Во View разрешены импорты `usePresenter`, CSS Module, подкомпонентов
  и типов, необходимых для JSX и props.
- Состояние, эффекты, обработчики событий, валидацию, бизнес-вычисления,
  подготовку данных и обращения к API размещай в `usePresenter`.
- Во View допустима логика отображения, включая `.map()` для вывода списков,
  условный JSX и выбор CSS-классов.

## Разделение логики

Для удобства чтения разделяй сложную логику presenter на небольшие файлы
по ответственности. Размещай их рядом с `usePresenter.ts`.

Логику, нужную нескольким компонентам, выноси в отдельный общий хук
или функцию.

## Вложенные компоненты

Подкомпонент, используемый одним родителем, размещай внутри папки родителя
в собственной папке.

## Общие компоненты и область использования

Общие компоненты конкретной части приложения размещай в папке `components`
в ближайшем общем родительском каталоге двух или более потребителей.

Для `P/components/Shared` разрешены потребители в каталоге `P` и во всём
его поддереве. Это ограничение действует также при реэкспортах.

В примере `Overview` и `Details` используют `StatusBadge`,
а `Summary` принадлежит `Overview` и отображает props.

```text
Dashboard/
├── Dashboard.tsx
├── usePresenter.ts
├── Dashboard.module.css
├── Overview/
│   ├── Overview.tsx
│   ├── usePresenter.ts
│   ├── Overview.module.css
│   └── Summary/
│       ├── Summary.tsx
│       ├── types.ts
│       └── Summary.module.css
├── Details/
│   ├── Details.tsx
│   ├── usePresenter.ts
│   └── Details.module.css
└── components/
    └── StatusBadge/
        ├── StatusBadge.tsx
        ├── usePresenter.ts
        ├── types.ts
        └── StatusBadge.module.css
```

## UI-kit

Общие UI-компоненты приложения размещай в `src/ui-kit`.
Они доступны компонентам во всём дереве `src`.
