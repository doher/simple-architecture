# Стиль кода

- Ставь пустую строку после блока, если за ним на том же уровне следует новая
  инструкция.
- Выноси сложные условия в переменные с именами, которые объясняют смысл
  проверки. Простые условия записывай на месте.
- Предпочитай ранний выход, например `return` или `continue`, если он
  позволяет убрать `else` и упрощает чтение кода.
- Используй браузерные API по их именам, без обращения к `window`.
